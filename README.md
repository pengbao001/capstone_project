# syn_microservice
- 'services/api'        : backend API service
- 'services/worker'     : background worker
- 'services/ui'         : frontend UI
- 'artifacts/'          : shared artifacts/output

## Build & run
Clone the project, unzip syn_microservice and run this command from your terminal - 
```code
cd syn_microservice
```
```code
docker compose up --build
```
## Open
API: http://0.0.0.0:8501/

## Stop
```code
docker compose down
```
